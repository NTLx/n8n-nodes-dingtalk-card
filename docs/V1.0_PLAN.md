# v1.0.0 stable convergence

v1.0 converges the presentation, request-action interaction, controlled A2UI, reliability, and reusable workflow-layer assets validated across v0.4–v0.9 and the v1.0.0-beta.1 connected-instance gate. It follows [DESIGN.md](DESIGN.md): transport stays in the plugin; routing, business policy, durable state, and optional AI orchestration stay in reusable workflows. Supported scope is Node `>=24 <25` and n8n 2.44.x. Form and Selection remain deferred. Callback dedupe is process-local; there is no durable exactly-once or Create-upsert guarantee.

The v1.0.0 stable promotion does not add runtime behavior relative to `1.0.0-beta.1`; it changes release metadata/policy and records completed acceptance. The beta package passed Node 24 quality and n8n-workflow 2.44.0/2.44.2 packed-artifact compatibility CI, public npm provenance verification, and supported n8n UI upgrade. Connected acceptance then verified reusable Notification and Report Hubs with real group Create/replacement Update, direct-message Create/replacement Update, Action Router fail-closed and allowlisted branches, and one real normalized `ACK` callback after Trigger deactivate/reactivate. The temporary listener was unpublished after acceptance.

The workflow assets contain no credentials, private targets, templates, or business system references. Universal-v1 URLs are displayed as text only. Full report content belongs in an access-controlled destination outside cards. State and durable idempotency remain workflow-owned.
