# v1.0.0 stable acceptance and closure

v1.0.0 is released. This record closes stable acceptance for the presentation, request-action interaction, controlled A2UI, reliability, and reusable workflow-layer assets. It follows [DESIGN.md](DESIGN.md): transport stays in the plugin; routing, business policy, durable state, and optional AI orchestration stay in reusable workflows. Supported scope is Node `>=24 <25` and n8n 2.44.x. Form and Selection remain deferred. Callback dedupe is process-local; there is no durable exactly-once or Create-upsert guarantee. Public artifact and CI evidence are in the [stable release record](VERIFICATION.md#v100-stable-public-release-2026-10-25).

The v1.0.0 stable promotion adds no runtime behavior relative to `1.0.0-beta.1`; it records completed acceptance and stable release metadata. The package passed Node 24 quality and n8n-workflow 2.44.0/2.44.2 packed-artifact compatibility CI, public npm provenance verification, and supported n8n UI upgrade. Connected acceptance verified reusable Notification and Report Hubs with real group Create/replacement Update, direct-message Create/replacement Update, Action Router fail-closed and allowlisted branches, and one real normalized `ACK` callback after Trigger deactivate/reactivate. After the stable upgrade, a separate read-only schema check confirmed both v1 nodes and their expected operation/A2UI/callback fields loaded; it did not mutate n8n or operate workflows, credentials, or community nodes. The temporary listener was unpublished after acceptance.

The workflow assets contain no credentials, private targets, templates, or business system references. Universal-v1 URLs are displayed as text only. Full report content belongs in an access-controlled destination outside cards. State and durable idempotency remain workflow-owned.
