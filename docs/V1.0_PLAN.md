# v1.0.0-beta.1 convergence candidate

This beta converges the presentation, interaction, controlled A2UI, and reliability work already validated in v0.4–v0.9. It follows [DESIGN.md](DESIGN.md): transport stays in the plugin; routing and business policy stay in reusable workflows. Scope is Node `>=24 <25` and n8n 2.44.x. The supported callback path is request-action only; Form and Selection remain deferred. Callback dedupe is process-local; there is no durable exactly-once or Create-upsert guarantee.

Beta.1 release gates: on Node 24 run clean install, lint, typecheck, build, full tests, package verification, production dependency audit, release-ref self-test/simulation, YAML parse, and diff checks. On a connected n8n 2.44.x/DingTalk instance, import the examples, bind the operator's own credential/template/target, and repeat scoped group/DM Create, Update, streaming/finalization where applicable, request-action callback, replacement Update, lifecycle/reconnect, and package install/update acceptance. These live gates are not asserted complete by this candidate.

The workflow assets contain no credentials, private targets, templates, or business system references. Universal-v1 URLs are displayed as text only. Full report content belongs in an access-controlled destination, outside cards. State and durable idempotency remain workflow-owned.
